
# Writing With Markdown  
  
There are several good reasons to write in markdown. Markdown is a simple,  
human readable markup language for writing prose. This means it's suitable  
for everything from email and message board comments to full-fledged novels.  
The syntax is easy to learn, literally taking all of fifteen minutes.  
There are several variants, or flavors, which can be somewhat more complicated  
but whatever species of Markdown you choose is going to be fairly easy to  
master.  
  
## Here is a basic primer:  
  
Put an empty line between paragraphs. To break a line end it with either two  
spaces or a backslash \  
  
Emphasis/Italics is rendered by bracketing words in *asterisks*.  
  
For bold use **double asterisks**  
  
For bold and italic use ***triple asterisks*** at each end.  
  
To print the asterisks rather than use them for emphasis, precede the character  
with a backslash, like this: `\*`  
  
>Use a leading greater-than sign (angle bracket) to set a paragraph off as\  
a block quote.  
  
To display code, verbatim, surround the inline code with `back ticks`.  
  
For code blocks use *three back ticks* in a row above and below the block.  
  
Headers are designated by lines beginning with octothorps.  
One octothorp (#) is a level one header. Three octothorps (###)  
is a level three header, etcetera.  
  
If you need to link to a website put the name in brackets, followed by the  
address in parenthesis, like this: [Technonomicon 2.0](https://xline0.wixsite.com/technonomicon)  
  
Include an image, on its own line, with a similar structure to a link but with  
a leading exclamation point:  
![description](http://link-to-picture)  
  
<center>  
  
Light html elements are generally accepted, as well as CSS styling for more  
advanced users. Use the center tag to center content horizontally.  
  
</center>  
  
Each line of a bullet list is begun with a hyphen `-`.  
  
Each line of a numbered list is begun with a number followed by a period: `1.`  
`2.` etc. Note that the parser should render them in an ascending sequence  
regardless of the actual number that is typed.  
  
This basically describes markdown but certain flavors take it a step further  
with tables, footnotes, and other elements.  
  
* * *  
  
3 asterisks on their own line make a section break, like `<hr />`  
  
A simple table would be constructed something like  
this:  
  
| column 1 | column 2 |  
| :--- | :--  
| info | information |  
  
An inline footnote would be like this^[this is a footnote].  


| columna 1 | columna 2 |
| --------- | --------- |
| datos 1   | datos 2   |

  
* * *  
  
Overall it is quite simple, quick, and easy to learn, and you can write a  
whole novel with it.
